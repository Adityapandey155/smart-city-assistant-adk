# Smart City Assistant (Google ADK)

A Smart City Assistant built using Google Agent Development Kit (ADK) and Gemini.

## Features

- Get current time for supported cities
- Get real-time weather information using WeatherAPI
- Perform mathematical calculations
- Tool-based AI agent architecture
- Powered by Google Gemini

## Technologies Used

- Python
- Google ADK
- Gemini Flash
- WeatherAPI
- pytz
- requests
- simpleeval

## Available Tools

### 1. Current Time Tool
Returns the current local time for supported cities.

Example:
- What is the time in Delhi?
- Current time in Tokyo

### 2. Weather Tool
Returns live weather information.

Example:
- What's the weather in London?
- Weather in New York

### 3. Calculator Tool
Safely evaluates mathematical expressions.

Example:
- Calculate 25 * 17
- What is (100 + 50) / 3?
